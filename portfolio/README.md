# Manjurahmad Tamboli Portfolio

This is a standalone Vite + React portfolio application. It does not share routing, assets, or runtime dependencies with the sibling WayFinder application.

## Run locally

```powershell
cd portfolio
npm.cmd install
npm.cmd run dev
```

## Build

```powershell
cd portfolio
npm.cmd run build
```

## Deploy to Vercel

Import this repository and select `portfolio` as the Vercel Root Directory, or deploy from this directory:

```powershell
cd portfolio
npx vercel --prod
```

Before deploying, replace the canonical URL placeholder in `index.html` with the production portfolio domain.
